# Working Hours Manager

今日1日の勤怠を入力して、実働時間と残業時間を確認

## How to use

1. 出勤時間を入力
2. 退勤時間を入力
3. 休憩時間を入力
4. 実働時間と残業時間が自動で表示
   - 設定画面で所定労働時間を h:mm 形式で設定

### Inputs

- 出勤時間: 勤務を開始した時刻
- 退勤時間: 勤務を終了した時刻
- 休憩時間: その日の休憩時間の合計分数
- 所定労働時間: 1日あたりの基準労働時間。初期値は 7:40

### Rule

- 実働時間 = 退勤時間 - 出勤時間 - 休憩時間
- 残業時間 = 実働時間 - 所定労働時間

## Errors

次のような入力では計算せず、画面にエラーメッセージを表示

- 退勤時間が出勤時間以前
- 休憩時間が勤務時間を超えている
- 休憩時間に 0 未満の値を入れている
- 所定労働時間が h:mm 形式になっていない

## Dependencies

- `mise`
- `pnpm`

### Launch

1. 依存関係をインストール

```bash
pnpm install
```

2. 開発サーバーを起動します。

```bash
pnpm dev
```

3. 表示されたローカル URL をブラウザで開きます。

### Build

```bash
pnpm build
```
